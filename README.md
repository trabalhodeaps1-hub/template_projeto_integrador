### 3.MINIMUNDO<br>
Uma empresa necessita de um sistema para registrar e acompanhar problemas que ocorrem em qualquer setor. Atualmente, os funcionários comunicam os problemas de maneira manual, dificultando o controle das solicitações e o acompanhamento das soluções.
No novo sistema, qualquer funcionário poderá registrar um problema, informando a área da empresa onde ocorreu (como TI, Recursos Humanos, Financeiro, Produção ou Manutenção), uma descrição, a data e o nível de prioridade.
Após o registro, o problema será encaminhado para um supervisor ou colaborador encarregado de resolver a ocorrência. Esse responsável poderá atualizar o status do chamado (Aberto, Em andamento, Resolvido ou Cancelado), registrar observações sobre a solução adotada e informar a data de conclusão.
O funcionário que registrou o problema poderá acompanhar o andamento da solicitação e verificar quando ela for concluída. O sistema também permitirá consultar o histórico de problemas registrados, identificar quais áreas possuem maior quantidade de ocorrências e gerar relatórios para auxiliar a gestão da empresa.

#### 7 Descrição dos dados 
    [objeto]: [descrição do objeto]
    
  • DEPARTAMENTO: Tabela que armazena os setores industriais da empresa DevCom. 
    • num_depto: Número identificador único do departamento (PK).
    • nome_depto: Nome oficial do departamento.
    • rg_gerente: RG do empregado associado como gerente do departamento (FK). 
    
  • EMPREGADO: Tabela que armazena as informações dos funcionários da empresa.
   • rg_empregado: Registro Geral do funcionário (PK).
   • nome_empregado: Nome completo do colaborador.
   • rg_supervisor: RG do supervisor direto do funcionário (FK autorelacionada).
   • num_depto: Número do departamento ao qual o empregado pertence (FK).
   
  •  PROJETO: Tabela que armazena os projetos de resolução e manutenção industrial.
   • num_projeto: Código identificador único do projeto (PK).
   • nome_projeto: Nome descritivo do projeto.
   
  • TRABALHA_EM (Atribuição): Tabela associativa entre Empregado e Projeto.
   • rg_empregado: RG do empregado alocado (PK, FK).
   • num_projeto: Código do projeto alocado (PK, FK).
   • horas: Quantidade de horas trabalhadas/alocadas pelo empregado no projeto.
   

  •  DEPENDENTE: Tabela que registra os dependentes dos empregados.
   • id_dependente: Identificador do dependente (PK).
   • rg_empregado: RG do empregado responsável pelo dependente (FK).
   • nome_dependente: Nome completo do dependente.
   • parentesco: Tipo de relação com o empregado (Filho, Cônjuge, etc.).
   • data_nasc: Data de nascimento do dependente.
   • sexo: Sexo do dependente (M/F).
